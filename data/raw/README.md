# Raw Research Data

This directory contains the original research dataset used for development of the MEDISCOPE Loss to Follow-Up (LTFU) prediction models.

The source dataset used during this project was:

`LTFU in HIV DataSet NDR.xlsx`

The dataset is intentionally **not included in the public Git repository**.

Reasons include:

- data-governance and redistribution considerations;
- separation of research data from source code;
- repository size;
- prevention of accidental publication of source-derived health-programme data.

The local modelling pipeline expects the authorised source dataset to be placed at:

`data/raw/LTFU in HIV DataSet NDR.xlsx`

The dataset used for machine-learning research is separate from the synthetic patient records used by the MEDISCOPE demonstration web application.
