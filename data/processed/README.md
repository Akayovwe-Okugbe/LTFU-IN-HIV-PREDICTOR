# Processed Data

This directory contains intermediate and final datasets generated by the MEDISCOPE preprocessing and feature-engineering pipeline.

Generated files include:

- `01_dates_converted.parquet`
- `02_feature_engineered.parquet`
- `03_train.parquet`
- `03_test.parquet`

These files are intentionally excluded from Git because they are derived artefacts and can be regenerated from the authorised source dataset using the project pipeline.

```powershell
python -m src.preprocessing
python -m src.features
